# PPS Labs – Programming for Problem Solving

This repository contains C programming laboratory assignments completed during my **First Year of Electronics and Communication Engineering (ECE)** at **MIT World Peace University (MIT-WPU), Pune**.

## Course & Student Details

- **Course:** Programming for Problem Solving (PPS)
- **Program:** B.Tech Electronics and Communication Engineering (First Year)
- **Institution:** MIT World Peace University (MIT-WPU), Pune

## Lab Assignments Index

### Lab 3: Basic Arithmetic Operations

- Menu-driven C program to perform basic arithmetic operations, including addition, subtraction, multiplication, and division.

### Lab 4: Matrix Operations

- C program to perform basic matrix operations, including the addition of two matrices.

### Lab 5: String Operations

- Menu-driven C program to perform various string operations using built-in string handling functions from the `string.h` library.

### Lab 6: Functions & Recursion

- **6(A):** C function to compute the factorial of a number using recursion.
- **6(B):** C function to compute the factorial of a number without recursion (iterative approach).

### Lab 7: Structures & Student Records

- C program using an array of structures to accept and store student details and display their results.

### Lab 8: Pointers & Parameter Passing

- C function to swap two numbers using pointers (Call by Reference).

### Lab 9: File Handling

- C program to copy the contents of one file into another using standard file handling operations.

### Lab 10: Calendar Generation

- C program to generate and print a complete month-by-month calendar for a given year.

## Tools & Environment

- **Programming Language:** C
- **Compiler:** GCC
- **IDE:** Visual Studio Code / Online C Compiler
